# The installation reminders go here

`cheatsheet.json` holds one entry per rule - topic, the rule in plain words,
the clause and page as printed in the owner's copy of ABYC E-11, and the
situations it applies to (`always`, `engine_space`, `bundled`, `parallel`,
or a load type such as `inverter`). `npm run cheatsheet` renders it to
`cheatsheet.md` and `cheatsheet.html`.

Entries are authored from the owner's own export of the standard and
confirmed against the page in the desktop app; an entry marked `draft` is
shown as such. Nothing here is written from memory.
